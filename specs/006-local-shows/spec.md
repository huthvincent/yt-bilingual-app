# 规格：本地剧集

**状态：** 已实现 ｜ **对应代码：** `backend/main.py`（`parse_srt`、`list_shows`、`process_subtitle`）、`frontend/src/components/ShowBrowser.tsx`

---

## 目标
不止 YouTube——让用户用同一套双语学习体验刷自己的剧（美剧、纪录片等），只要有 SRT 字幕。

## 用户故事
- 作为用户，我想把自己的 `.srt` 字幕放进项目，就能**双语看这部剧**。
- 作为用户，我想按**剧 → 季 → 集**浏览选择。

## 功能需求
- **必须**：识别 `subtitles/<剧名>/S01/E01.srt` 这种目录结构，列出可用的剧、季、集。
- **必须**：处理某一集时，复用与 YouTube **完全相同**的翻译、生词高亮、缓存逻辑。
- **必须**：已处理的集标记出来，再次打开秒开。
- **必须**：本地剧集无真实播放器，用计时器模拟播放进度以驱动字幕同步。

## 验收标准
- [ ] 把 `subtitles/<剧>/S01/E01.srt` 放好后，首页"本地剧集"能看到这部剧。
- [ ] 选剧 → 选季 → 选集，处理后得到与 YouTube 一致的双语字幕。
- [ ] 已处理的集有标记，再次打开为秒开。

## 边界与非目标
- 只解析 SRT 格式；不内置视频画面（仅字幕 + 模拟时间轴）。
- `subtitles/` 内容不入库（版权，见 [宪法原则 6](../../.specify/memory/constitution.md) 与 `.gitignore`）。
