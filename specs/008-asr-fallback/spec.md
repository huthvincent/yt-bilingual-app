# 规格：无字幕转写回退

**状态：** 已实现（可选依赖） ｜ **对应代码：** `backend/main.py`（`_asr_available`、`_transcribe_audio_with_whisper`）

---

## 目标
大量 YouTube 视频没有人工/自动英文字幕。让这些视频也能学——没字幕就本地转写音频。

## 用户故事
- 作为用户，我粘贴的视频没有字幕时，希望应用**自动转写**它的音频，而不是直接报错让我放弃。

## 功能需求
- **必须**：抓不到英文字幕时，若本地装了 `faster-whisper`，则下载音频并本地转写，再走正常翻译管线。
- **必须**：转写阶段通过 SSE `stage: "asr"` 事件告知前端，界面提示"本地转写中"（首次会下载模型）。
- **必须**：未安装 `faster-whisper` 时，错误提示明确告诉用户**怎么开启**（`pip install faster-whisper`），而非笼统报错。
- **应当**：Whisper 模型大小可配（`WHISPER_MODEL`，默认 `base`）。

## 验收标准
- [ ] 装了 `faster-whisper`：处理无字幕视频时进入"本地转写中"，转写完继续翻译。
- [ ] 没装：处理无字幕视频时给出明确的"如何启用转写"提示。
- [ ] 转写产出的字幕与正常字幕走相同的翻译、缓存、续译流程。

## 边界与非目标
- ASR 是**可选**依赖，默认不安装；不装时仅"有字幕"的视频可用。
- 转写质量受 Whisper 模型大小影响；时间戳精度低于官方字幕。
- 转写较慢，仅作为"无字幕"兜底，不替代官方字幕。
