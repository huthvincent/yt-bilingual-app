# 规格：精听训练

**状态：** 已实现 ｜ **对应代码：** `frontend/src/App.tsx`、`frontend/src/components/TranscriptBlock.tsx`、`frontend/src/components/VideoPlayer.tsx`

---

## 目标
把"被动看双语字幕"升级成"主动精听训练"。精听最高频的动作是重复某句、先听后看，这些都要顺手可达。

## 用户故事
- 作为用户，我想**反复听同一句**直到听懂，不用每次手动拖回去。
- 作为用户，我想**先盲听、再看英文**核对自己。
- 作为用户，我想**放慢语速**听清连读。
- 作为用户，我想**用键盘**操作，不用全程点鼠标。

## 功能需求
- **必须**：听写模式——英文默认模糊，点击或快捷键揭示；中文译文默认隐藏。
- **必须**：单句循环——锁定当前句反复播放；点别的句子可重新锁定。
- **必须**：倍速——0.5×–2× 快捷切换。
- **必须**：键盘快捷键——`空格` 播放/暂停、`←`/`→` 上一句/下一句、`R` 重播本句、`L` 单句循环。
- **必须**：译文显示模式——全显 / 仅当前句 / 隐藏，全局策略跨会话记忆，可逐句临时覆盖。
- **必须**：以上在 YouTube 视频和本地剧集两种模式下都生效。

## 验收标准
- [ ] 开听写模式后，英文模糊，点击句子可揭示。
- [ ] 按 `L` 锁定当前句，播放到句尾自动跳回句首循环。
- [ ] 倍速选 0.75× 后，YouTube 实际以该速率播放。
- [ ] 焦点不在输入框时，`空格`/`←`/`→`/`R`/`L` 均按约定生效。
- [ ] 译文模式切到"仅当前句"，只有正在播的句子显示中文，刷新后仍是该模式。

## 边界与非目标
- 倍速控件在本地剧集模式下隐藏（本地用计时器模拟播放，无真实播放器）。
- 不做跟读评分（属未来路线）。
