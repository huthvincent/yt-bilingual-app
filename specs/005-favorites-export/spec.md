# 规格：收藏与导出

**状态：** 已实现 ｜ **对应代码：** `backend/routes_user.py`（`/api/favorites`）、`frontend/src/components/FavoritesModal.tsx`、`frontend/src/lib/exporter.ts`

---

## 目标
打通学习闭环的最后一环——把"看过/查过"沉淀成"可复习"。收藏不能是死胡同，必须能导出到真正的复习工具。

## 用户故事
- 作为用户，我想**星标**重要的句子和生词，连同它们的来源语境一起存下来。
- 作为用户，我想把收藏**导出到 Anki** 做间隔重复，或导成表格自己整理。

## 功能需求
- **必须**：可收藏两类——整句、单词（生词）；都带来源句、视频、时间点。
- **必须**：收藏持久化到后端（`favorites.json`），后端不可用时退回 localStorage。
- **必须**：导出 **Anki 可导入的 TSV**（正面英文 / 背面中文+例句 / 标签）。
- **必须**：导出**完整 CSV**（含类型、英文、中文、语境、视频 id、时间点、日期）。
- **应当**：收藏夹按时间分组（今天 / 昨天 / 更早）。

## 验收标准
- [ ] 看视频时点句子旁星标，该句进入收藏夹，带时间点。
- [ ] 查词卡里点星标，该词进入收藏夹（生词类型，带来源句）。
- [ ] 收藏夹点"导出 Anki"，下载的 TSV 能被 Anki 正常导入成卡片。
- [ ] 点"导出 CSV"，下载的表格含完整上下文列。

## 边界与非目标
- 不内置复习/间隔重复（导出到 Anki 承担复习；应用内复习属未来路线）。
- 导出是一次性文件下载，不做云同步。
