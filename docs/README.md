# 文档导航

本项目的文档按 [spec-kit](https://github.com/github/spec-kit) 的规格驱动方式组织。**除根目录 README 外，所有文档均为中文。**

## 从这里开始

| 文档 | 讲什么 |
|---|---|
| [项目宪法](../CONSTITUTION.md) | 最高准则：产品与工程原则。改代码前先读 |
| [系统架构](./架构.md) | 前后端怎么协作、数据怎么流、代码怎么分区 |
| [设计语言](./设计语言.md) | 暗色 UI 设计规范：排版、颜色、材质、动效、组件配方 |
| [开发指南](./开发指南.md) | 怎么跑、怎么改、规格驱动工作流、部署 |

## 功能规格

每个核心功能在 [`specs/`](../specs/) 下有一份规格（讲"做什么、为什么"），复杂的还有技术方案。索引见 [specs/README.md](../specs/README.md)。

## 模板

新功能写规格时用 [`.specify/templates/`](../.specify/templates/) 里的模板：规格、技术方案、任务清单。

## 产品介绍

面向用户的产品介绍在仓库根目录的 [README](../README.md) / [README_zh](../README_zh.md)（含动图演示）。
