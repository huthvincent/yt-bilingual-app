# 开发指南

面向开发者：怎么跑起来、怎么改、怎么遵循规格驱动的工作流。

---

## 本地跑起来

环境要求：Node 18+、Python 3.10+、一个免费的 [Gemini API Key](https://aistudio.google.com/apikey)。

```bash
./setup.sh                       # 安装前后端依赖
cp .env.example .env             # 填入 GEMINI_API_KEY
./start_app.command              # macOS 一键启动
```

手动启动：

```bash
# 后端
cd backend && source venv/bin/activate && uvicorn main:app --port 8000
# 前端
cd frontend && npm run dev        # http://localhost:5173
```

## 环境变量

| 变量 | 必填 | 说明 |
|---|---|---|
| `GEMINI_API_KEY` | 是 | 翻译、总结、词典都靠它 |
| `WHISPER_MODEL` | 否 | 无字幕转写的 Whisper 模型大小，默认 `base` |
| `CORS_ORIGINS` | 公网部署必填 | 允许的跨域来源，逗号分隔；默认 `*` |
| `API_AUTH_KEY` | 公网部署必填 | 设置后所有 `/api` 请求必须带 `X-API-Key`，保护 Gemini 配额 |
| `VITE_API_BASE` / `VITE_API_KEY` | 否 | 前端指向远程后端 / 携带其 Key |
| `HISTORY_DIR` / `SUBTITLES_DIR` | 否 | 自定义缓存 / 本地剧集目录 |

> **安全红线**（[宪法原则 6](../.specify/memory/constitution.md)）：公网部署前必须设 `API_AUTH_KEY` + `CORS_ORIGINS`。`start_app.command` 的公网隧道默认关闭，需显式 `ENABLE_TUNNEL=1` 且已设 `API_AUTH_KEY` 才会开。

## 验证改动

- 前端：`cd frontend && npx tsc -b`（类型检查，作为提交门禁）+ `npx vite build`。
- 后端：`cd backend && venv/bin/python -m py_compile main.py`。
- UI 改动：起开发服务器实际看效果，别只靠想象。

## 规格驱动的工作流

参考 [spec-kit](https://github.com/github/spec-kit) 的方式管理。**较大的新功能**按这个顺序走：

1. **读宪法**：先看 [项目宪法](../.specify/memory/constitution.md)，确认方向不跑偏。
2. **写规格**：在 `specs/` 下新建 `00X-功能slug/spec.md`（用 [模板](../.specify/templates/spec-template.md)），只讲"做什么、为什么"。
3. **写方案**：复杂功能再写 `plan.md`（[模板](../.specify/templates/plan-template.md)），讲"怎么做"。
4. **拆任务**：必要时写 `tasks.md`（[模板](../.specify/templates/tasks-template.md)），逐项实现、逐项提交。
5. **实现 + 回填**：写代码，更新规格状态为"已实现"，补上对应代码路径。

小改动（改文案、修 bug、调样式）可直接做，不必走全流程。所有 UI 改动须符合 [设计语言](./设计语言.md)。

## 加一个新功能的清单

- [ ] 在 `specs/` 写 spec（复杂的再加 plan）
- [ ] 后端逻辑写进 `backend/main.py`；纯前端逻辑放 `frontend/src/lib/`，UI 放 `frontend/src/components/`
- [ ] 复用既有设计配方，不发明新样式
- [ ] 花钱/耗时的结果要落盘缓存（[宪法原则 4](../.specify/memory/constitution.md)）
- [ ] `tsc -b` 通过；UI 在浏览器里实测
- [ ] 更新相关文档

## 重新生成 README 媒体

```bash
cd scripts && npm install
APP_URL=http://localhost:5173 node capture.mjs all
```

用 Playwright 驱动系统 Chrome 截帧、纯 JS（gifenc）编码 GIF，无需 ffmpeg。可单独录某个场景：`node capture.mjs hero|learning|dictionary|dictation|mobile|stills`。

## 部署

仓库带 `Dockerfile` / `railway.toml` / `Procfile`。部署要点：设好上面的安全环境变量；`HISTORY_DIR` 指向持久卷（缓存不丢）。
