# .specify/ — 规格驱动开发的模板

参考 [github/spec-kit](https://github.com/github/spec-kit)。项目宪法在根目录 [CONSTITUTION.md](../CONSTITUTION.md)。

| 模板 | 用途 |
|---|---|
| `templates/spec-template.md` | 新功能规格：做什么、为什么、验收标准 |
| `templates/plan-template.md` | 技术方案：怎么实现、取舍、风险 |
| `templates/tasks-template.md` | 任务拆解：有序可验证的实现清单 |

用法：新功能在 `specs/` 下建 `0XX-功能slug/`，复制对应模板填写。流程见 [开发指南](../docs/开发指南.md)。
