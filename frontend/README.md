# Lingua Nova — Frontend

React 19 + Vite + TypeScript + Tailwind. This is the web client only.

- Run: `npm install && npm run dev` (http://localhost:5173)
- Type-check / build: `npx tsc -b && npx vite build`

For the full project — setup, architecture, design language, and feature specs —
